# Sealand Haulage Limited — Landing Page

Informational landing page for **Sealand Haulage Limited**, a logistics company serving the oil and gas industry exclusively — rig moves, heavy haulage, and oilfield equipment transport.

This is a static, information-only site: it presents the company's services and contact details. There is no booking or ordering functionality by design.

## Structure

- `index.html` — the entire site (single file, no build step, no dependencies).

## Viewing locally

Open `index.html` in any browser.

## Deploying

Any static host works (GitHub Pages, Netlify, Vercel). For GitHub Pages: repo **Settings → Pages → Deploy from branch → main / root**.

## Customizing

The phone number and office location in the **Contact** section (`index.html`) are placeholders — replace them with the real ones.
